Architecture-only reconstruction: when explicitly selected, use its approved runtime plan
and review artifacts. This component supplies guidance, not a runtime implementation.
Do not create a native change, specs, needs, or tasks.md merely to reconstruct existing
architecture. Preserve product code, tests, current specs, manual documentation, and
ADR history. Describe evidence-backed structure, not an ideal DDD target. Distinguish
observed source/configuration, documented intent, inference, unknowns, and coverage
limits. Test source is not an executed result; configuration does not prove deployment.
Never invent goals, guarantees, historical alternatives, or decisions. Architecture-only
scopes can appear in documentation navigation without catalog entries.
Use safe available approved checks with actual results and visible gaps. Keep
publication separate from corrections. The host workflow retains its success/issues
reviews and blocked waiting for user input; ordinary resumption stays at the same
stage. Upstream recovery requires explicit authorization, not rerouting all publication
blockers. This schema does not implement that host state machine.
