# Equipment lending example

This is a fictional baseline and one proposed change, not an application.
The baseline includes a domain-model companion; the proposed model update remains
tracked in the active change until implementation and acceptance. No implementation or
acceptance verification is claimed. All seven delivery tasks remain open.

Read [the example documentation](openspec/README.md) and its
[change walkthrough](openspec/worked-change.md). To browse the standalone mdBook
with mdBook on `PATH`, run from this directory:

```sh
mdbook serve
```

`mdbook build` writes static HTML to `build/book/`. The schema is shared from the
guide's bundle; follow the handbook's example setup or run the integration tests,
which prepare an isolated copy with the schema installed.
