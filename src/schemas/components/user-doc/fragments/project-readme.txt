The optional user-doc component adds reader-focused guides, tutorials, explanations,
references, and troubleshooting starters. Maintained pages live at the selected
project-root documentation location (user-doc/ by default), separate from
the schema's template library and the optional arc42 handbook. Planning identifies
audiences, affected pages, delivery mappings, and checks inside the change; drafts are
optional. Apply updates mapped descriptive sources outside openspec/specs/** alongside
code in the development checkout, then checks actual pages and procedures. Drafts alone are not delivery.
Protected-tree proposals and dependent links follow separately authorized sync/archive-stage
integration through the base handoff; native spec sync does not publish
user documentation. Completed edits and successful checks are distinct from acceptance,
release, or site deployment. Existing documentation obligations still apply when this
optional component is not selected.
